# Source and licenses

Original component licenses remain intact. NESVM retains Nofrendo's GNU Library
GPL v2; Doom retains GPL-2.0-or-later. Doom shareware data has its separate
game license.

The [written offer](Source-offer.txt) covers complete required corresponding
source, modifications and build/relink materials for these and current A8,
MPE host and desktop GPL/LGPL components. Anyone may request them free through
[Issues](https://github.com/ziggystar12/MHS-GAME-SUPPORT/issues), identifying
release and component hash. It runs through at least 2 October 2029 and three
years after last distribution. Full matching build snapshots and earlier
required source/offer records are retained privately.

Prism+ is compiled code under [its existing license](../licenses/LICENSE-PRISM-PLUS.txt).
Its proprietary implementation and game compiler are not published here.
Required source archives and relink materials are supplied on request under
the written offer and are retained with the matching private build snapshots.
Earlier MIT grants and third-party rights remain intact. Notices accompany
all downloads. The A8 compiler is separate and unreleased.
