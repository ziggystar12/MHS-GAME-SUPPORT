# MHS Game Support

Keep this public repository focused on cartridge support, firmware and the
agreed examples. Use short, direct documentation. Game packers, commercial
originals, private renderer source and unrelated game packages stay out.

Downloads are limited to NESVM, Doom, cartridge firmware and HamsterOS for
Teensy, KFF2 and A8PicoCart. Other released VMs are compiler-only. Check this
scope inside combined ZIPs before updating release assets. Publish only the five
complete setup/player ZIPs; no checksum download, standalone duplicates or
source archives. Keep matching source snapshots privately under written offers.

Preserve component notices and matching engine source archives. Keep native
AGI-64 carts, Teensy MPE and KFF2 MPE formats distinct. Label proposed ports
and hardware-test limits accurately. Test the files and integration references
before publishing. Stage named paths and verify the actual remote after sync.
