# MPE host

Use the supplied stock TeensyROM firmware. From the stock text menu, install MPE.TRH, then fully power the C64 off and on. Preserve VMS/MPE registration files. Launch VM .MPE files directly; replace each MPE file to update its runtime. This host replaces the extension slot previously occupied by VMBoot.TRH. No build flashes a device.

The revised standalone VM route passes software checks. Physical acceptance of this exact host remains pending.
