# MPE host

MPE host **1.4.21** for official **TeensyROM+ 0.9** (Fab 0.4). This update adds automatic SD diagnostic reports.

Install `MPE.TRH` from the stock text menu, then fully power the C64 off and on. Keep the supplied `VMS/MPE` registration trio together. Launch VM `.MPE` files directly; replace each package to update its runtime. This host replaces the extension slot previously occupied by `VMBoot.TRH`.

Software checks passed for this exact host, its ABI, module admission, desktop controls, demo runtime and emitted C64 client. The official stock firmware remains unchanged. Physical acceptance and full-game operation of this host remain unverified. See [VERIFICATION.json](VERIFICATION.json) for the checked identities and scope.

Turbo64 0.9.33 currently requires the custom 1.4.47 firmware. Its accelerated CPU profile has not been integrated into this standard host.
