Compute's Gazette Enhanced Sidplayer guest programs

These unmodified 6502 guest programs are credited to Craig Chamberlain / COMPUTE! (1986) in their source. Retrieved from libsidplayfp commit b72679c7d7f77336b6ae7137dbf3be3654e0ff9a. The upstream GPL-2.0 license is included in COPYING. These are executed in the isolated music CPU; no libsidplayfp C++ code is used. Sources and the reproducible assembly script are supplied alongside the derived byte arrays.
